# Product Requirements Document (PRD)

## 1. Identificação
- **Aluno:** Vinicius Campos de Ramos
- **Projeto:** Taverna Hub (Gestor de Campanhas de RPG)

## 2. Descrição
O Taverna Hub é uma aplicação web voltada para jogadores e mestres de RPG de mesa. O propósito do sistema é resolver o problema da desorganização de fichas e anotações de sessões, oferecendo uma plataforma centralizada para cadastrar campanhas e registrar personagens de forma digital e rápida.

## 3. Atores do Sistema
- **Mestre (Visitante/Usuário):** O criador do mundo, que gerencia as campanhas e sessões.
- **Jogador (Visitante/Usuário):** O participante que cria e gerencia a ficha do seu personagem.

## 4. Histórias de Usuário (Escopo)
- Como Mestre, eu quero cadastrar uma nova campanha informando nome e sistema, para manter o registro das minhas mesas organizado.
- Como Jogador, eu quero criar a ficha do meu personagem com nome, raça e classe, para não perder meus atributos entre as sessões.
- Como Jogador, eu quero que os dados do formulário sejam salvos localmente enquanto digito, para não perder o progresso caso a página recarregue acidentalmente.
- Como Usuário, eu quero visualizar a previsão do clima atual na tela inicial, para usar a informação como imersão narrativa no início da sessão.
