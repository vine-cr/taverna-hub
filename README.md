# Taverna Hub

O Taverna Hub é uma aplicação web voltada para jogadores e mestres de RPG de mesa, oferecendo uma plataforma centralizada para cadastrar campanhas e registrar personagens de forma digital e rápida.

## Tecnologias e Dependências

*   **Framework CSS:** Bootstrap
*   **API Pública:** OpenWeather API

### Justificativa das Escolhas

Para o desenvolvimento das interfaces, o **Bootstrap** foi escolhido por ser um framework extremamente sólido, com um sistema de grid responsivo impecável que facilita a adaptação fluida entre dispositivos móveis e desktops. Sua extensa biblioteca de componentes prontos, como Cards, Modals e Navbars, acelera o desenvolvimento. Ao mesmo tempo, a facilidade de integração e customização com SCSS permite refatorar o estilo para garantir que a identidade visual rústica da taverna seja mantida sem engessar o código. Além disso, a saúde do projeto no GitHub é excelente, com atualizações constantes e uma comunidade ativa que garante compatibilidade e segurança.

Para enriquecer a experiência de jogo, a aplicação consumirá a **OpenWeather API**. Trazer dados climáticos do mundo real diretamente para o painel do mestre oferece um gancho narrativo criativo para definir a ambientação inicial de sessões de sistemas como D&D 5e ou Tormenta 20. Essa funcionalidade transforma um dado simples de clima em uma ferramenta de imersão, ajudando a ditar o tom da aventura antes mesmo de os dados rolarem.
